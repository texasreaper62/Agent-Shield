# Changelog

## 1.0.0 — 2026-03-20

### Added
- Initial release of Agent Shield VS Code extension.
- Real-time inline scanning of AI prompts and agent code.
- Detection patterns for instruction override, role hijacking, data exfiltration, social engineering, and system prompt leak categories.
- Support for JavaScript, TypeScript, Python, and Markdown files.
- String literal extraction from template literals, f-strings, and triple-quoted strings.
- Commands: Scan File, Scan Selection, Toggle Inline Scanning.
- Configurable minimum severity level and category filtering.
- Keyboard shortcut Ctrl+Shift+S for scanning selected text.
