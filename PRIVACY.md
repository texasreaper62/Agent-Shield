# Privacy Policy for Agent Shield

**Last updated:** March 18, 2026

## Overview

Agent Shield is a security SDK for AI agents. It scans text inputs, outputs, and tool calls for AI-specific threats such as prompt injection, data exfiltration, and tool abuse. Your privacy is our top priority.

## Data Collection

**Agent Shield does not collect, store, transmit, or share any user data.** Period.

- No personal information is collected
- No agent conversations are tracked or sent externally
- No data is sent to external servers
- No analytics or tracking tools are used
- No API keys or accounts are required
- No cloud dependencies of any kind

## How It Works

All threat detection runs **entirely in your local environment** using pattern-matching logic bundled inside the SDK. When you scan text through Agent Shield, it is analyzed locally in your Node.js process. Nothing ever leaves your machine.

## Third Parties

Agent Shield does not share data with any third parties because Agent Shield does not collect any data.

## Changes to This Policy

If this privacy policy changes, the updated version will be posted here with a new "Last updated" date.
