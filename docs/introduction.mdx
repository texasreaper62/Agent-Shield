Agent Shield is a security SDK for AI agents. It scans inputs, outputs, tool calls, and retrieved context for prompt injection, data exfiltration, tool poisoning, confused-deputy attacks, and 40+ other AI-specific threats. All detection runs locally — no API keys, no cloud calls, no data leaves your environment.

```bash
npm install agentshield-sdk
```

## Where it fits

Agent Shield sits between your agent and the outside world. It works with the Anthropic SDK, OpenAI SDK (including the new `@openai/agents` SDK), LangChain, MCP servers, Express, Next.js, Vercel AI SDK, and Cloudflare Workers — usually as a one-line wrapper.
