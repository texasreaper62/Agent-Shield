Agent Shield runs at the edge. Wrap Workers AI, an AI Gateway endpoint, or any model fetch with one line.

## Setup

<Steps>
  <Step title="Install">
    ```bash
    npm install agentshield-sdk
    ```
  </Step>

  <Step title="Enable Node compat">
    In `wrangler.toml`:
    ```toml
    compatibility_flags = ["nodejs_compat"]
    compatibility_date = "2026-04-01"
    ```
  </Step>

  <Step title="Deploy">
    ```bash
    wrangler deploy
    ```
  </Step>
</Steps>

## Worker

```javascript
import { AgentShield } from 'agentshield-sdk';

const shield = new AgentShield({
  sensitivity: 'high',
  blockOnThreat: true,
  blockThreshold: 'high'
});

export default {
  async fetch(request, env, ctx) {
    if (request.method !== 'POST') {
      return new Response('Use POST', { status: 405 });
    }

    const { prompt } = await request.json();

    // Scan input
    const inputScan = shield.scanInput(prompt);
    if (inputScan.blocked) {
      return Response.json({
        error: 'Blocked by Agent Shield',
        category: inputScan.threats[0]?.category
      }, { status: 400 });
    }

    // Call Workers AI
    const response = await env.AI.run('@cf/meta/llama-3.1-8b-instruct', {
      prompt
    });

    // Scan output
    const outputScan = shield.scanOutput(response.response);
    if (outputScan.blocked) {
      return Response.json({ error: 'Response blocked' }, { status: 502 });
    }

    return Response.json({ response: response.response });
  }
};
```

## Notes

- Agent Shield works in Workers because it's pure JavaScript with zero native deps.
- LRU cache state lives in the isolate — across requests, until the isolate recycles.
- For shared state (rate limits, herd immunity), use Workers KV or Durable Objects with the `DistributedShield` adapter.

Full example: [`examples/cloudflare-workers-ai.js`](https://github.com/texasreaper62/Agent-Shield/blob/main/examples/cloudflare-workers-ai.js).
