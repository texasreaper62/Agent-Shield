Agent Shield ships **307 active detection patterns** organized into **51 categories**. Every pattern is plain JavaScript regex (no proprietary opaque models), versioned in source, and ReDoS-audited.

## Source

All patterns live in [`src/detector-core.js`](https://github.com/texasreaper62/Agent-Shield/blob/main/src/detector-core.js). Each pattern has a category, severity, and short description string.

```javascript
{
  category: 'prompt_injection',
  pattern: /ignore\s+(all\s+)?previous\s+(instructions|prompts)/i,
  severity: 'high',
  description: 'Direct instruction override'
}
```

## Adding your own

Use the plugin system to add custom patterns without forking:

```javascript
const { AgentShield, PluginRegistry } = require('agentshield-sdk');

PluginRegistry.register({
  name: 'my-pattern',
  detect(text) {
    if (/<my-internal-tag>/i.test(text)) {
      return { category: 'internal_leak', severity: 'high' };
    }
    return null;
  }
});

const shield = new AgentShield({ plugins: ['my-pattern'] });
```

Patterns run alongside the built-in 307. Same hot path, same caching.
